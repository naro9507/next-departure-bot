description: セッションの変更を docs/ の仕様書に反映する。API・DB・管理画面・インフラの実装が変更されたとき、または Stop hook から呼び出されたときに使用する。
---

今回のセッションで行った変更をもとに、`docs/` フォルダの仕様書を更新してください。

## 手順

1. **変更の特定**
   - `git log --oneline -10` で直近のコミットを確認する
   - `git diff HEAD~5..HEAD --stat` で変更ファイルを確認する
   - 変更したファイルがどの仕様書に影響するかを判断する:

   | 変更ファイル | 対応する仕様書 |
   |------------|--------------|
   | `src/handlers/search.ts` / `admin.ts` / `line.ts` / `alexa.ts` | `docs/api.md` |
   | `src/db/schema.ts` / `src/repository/` | `docs/database.md` |
   | `src/handlers/adminPage.ts` | `docs/admin.md` |
   | `terraform/` | `docs/infrastructure.md` |

2. **該当する仕様書を更新**
   - 追加・変更されたエンドポイント、フィールド、挙動を反映する
   - 削除された機能は仕様書からも削除する
   - 変更がなければそのファイルはスキップしてよい

3. **コミット & プッシュ**
   - いずれかの仕様書を変更した場合のみコミット・プッシュする
   - コミットメッセージ例: `仕様書を更新 (セッション反映)`

## 注意

- 実装内容そのものは変更しない。`docs/` だけを更新する
- コードから読み取れる事実（エンドポイント・型・バリデーション）を正確に記述する
- 推測や未実装の内容は書かない
